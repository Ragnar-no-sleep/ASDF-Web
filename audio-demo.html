💡 About Audio Feedback

This audio system uses the Web Audio API to generate sounds procedurally (no external files needed). All sounds are synthesized in real-time using oscillators, filters, and noise generators.

  • Click: Sharp white noise burst with bandpass filter
  • Hover: Soft sine wave descending sweep
  • Whoosh: Sawtooth sweep with lowpass filter
  • Success: Ascending three-note chord (C-E-G)
  • Error: Descending two-note interval (G-D)
  • Warning: Sustained note with vibrato
  • Burn: Crackling noise with bandpass filter
