# ASDF Philosophy

> Don't trust. Verify. Don't extract. Burn. Don't panic. Hold. This is fine.

---

## Core Tenets

### 1. Verify, Don't Trust
Every claim needs proof. Every metric needs a source. Code speaks louder than promises.
On-chain data is truth. Off-chain data is opinion.

### 2. Burn, Don't Extract
Three similar lines of code beat a premature abstraction. Simplify by removing, not by adding layers.
When something doesn't serve its purpose, burn it. Dead code, dead features, dead weight.

### 3. Hold, Don't Panic
Long-term vision over short-term hacks. Build for the next 1000 users, not the next feature request.
Fibonacci pacing: sprint, rest, reflect, build stronger.

## Phi Harmony

The Golden Ratio (phi = 1.618) is not decoration. It's structural.

### Work Distribution
- 61.8% implementation (building)
- 23.6% research (understanding)
- 14.6% planning (designing)

### Confidence Cap
Maximum certainty: **61.8%** (phi inverse). Absolute certainty is a lie.
Every decision carries uncertainty. Document it. Own it.

## Design Principles

### Minimalism with Purpose
Every element earns its place. No decoration without function.
Dark-first design. Light is the accent.

### Typography as Architecture
- **Inter** for human text (body, labels, navigation)
- **JetBrains Mono** for machine text (code, data, metrics)
- Phi-based type scale from 9px to 55px

### Color as Signal
- `#ea4e33` (ASDF orange) = accent, rare and intentional
- `#f59e0b` (gold) = secondary emphasis
- `#4ade80` (green) = success, positive change
- `#0a0a0a` (near-black) = canvas, the default

## Architecture Principles

### 1 File Per Page
Each page is self-contained: 1 HTML + 1 CSS + 1 JS.
No bundler dependencies. No framework lock-in. Direct serve.

### Security First
Fix vulnerabilities before adding features. Harden before scaling.
Helmet, CSP, rate limiting, CSRF, parameterized queries. Always.

### Progressive Enhancement
Works without JavaScript. Better with JavaScript. Best with wallet connected.

### Fork-Ready
Every tool page can be extracted and deployed independently.
The ecosystem shell (nav, themes, transitions) travels with the page.
