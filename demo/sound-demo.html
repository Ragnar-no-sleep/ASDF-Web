🔊 ASDF Sound System Demo

Settings Control Persistent

Toggle sound ON/OFF and adjust volume. Settings are saved to localStorage.

💡 Tip: Sounds are disabled by default. Enable them above to hear the demos below.

1. UI Interaction Sounds Subtle

Lightweight feedback for clicks and hovers. Click triggers automatically on all buttons below.

Click 800Hz sine, 50ms (buttons, links)
Hover 600Hz sine, 30ms (very subtle)

2. Feedback Sounds Clear

Success (C-E-G chord) and error (dissonant) sounds for transaction feedback.

Success 523-659-784Hz chord (C-E-G major)
Error 300-250Hz dissonant (square wave)

3. Action Sounds Contextual

Unique sounds for burns (descending), stakes (ascending lock), and unstakes (descending unlock).

Burn 200→100Hz sweep (sawtooth, descending)
Stake 400→800Hz sweep (triangle, ascending)
Unstake 800→400Hz sweep (triangle, descending)

4. Special Effects Optional

Additional sounds for notifications and transitions.

Notification 659-784Hz (E-G interval)
Whoosh 1200→400Hz sweep (fast transition)

Technical Details

  • Web Audio API — Synthesized sounds, no audio files required
  • Zero dependencies — Pure JavaScript, no external libraries
  • File size — ~8KB minified (sound-system.js)
  • Browser support — All modern browsers (Chrome, Firefox, Safari, Edge)
  • Settings persistence — localStorage (enabled/volume)
  • Default state — Disabled (user opt-in required)
  • Auto-integration — Attaches to buttons/links automatically when enabled
  • Performance — Negligible CPU usage, sounds < 500ms each
